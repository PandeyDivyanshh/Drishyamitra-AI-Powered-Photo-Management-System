📸 Drishyamitra
Drishyamitra is an AI-powered photo management system that organizes, searches, and shares your digital memories automatically. It replaces manual sorting with advanced facial recognition and a conversational AI assistant.
✨ Core Features
AI Face Recognition: Uses DeepFace (Facenet512, RetinaFace, MTCNN) to accurately detect and learn faces.
Smart Organization: Automatically groups photos into person-specific and event-specific folders.
Conversational Assistant: Powered by Groq NLP, allowing you to search your gallery using natural language (e.g., "Show me photos of Priya from last month").
Automated Sharing: Send photos directly to contacts via WhatsApp or Email using simple chat commands.
🛠️ Tech Stack
Frontend: React.js
Backend: Python / Flask
AI & NLP: DeepFace, Groq API
Integrations: WhatsApp API, SMTP/Email APIs

Individuals: Organizing chaotic personal and family photo dumps.
